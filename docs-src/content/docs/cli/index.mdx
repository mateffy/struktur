The Struktur CLI provides commands for data extraction and authentication management.

## Commands

- [installation](./installation) — Install and configure Struktur
- [extract](./extract) — Extract structured data from documents
- [auth](./auth) — Manage API tokens and default models
- [models](./models) — List available models by provider
- [verify](./verify) — Verify configuration and provider connectivity
