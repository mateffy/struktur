How to process multiple files

Process multiple files efficiently using shell pipelines or scripting with Struktur.

How to process multiple files

Batch processing with shell pipelines or scripts. About 3 minutes.

The problem: Process many files

You have a directory of documents to extract. You need efficient batch processing that handles errors and tracks progress.

Shell pipeline approach

For simple batch processing, use find with a loop:

find ./documents -name "*.pdf" -print0 | while IFS= read -r -d '' file; do
  echo "Processing: $file"
  struktur --input "$file" \
    --schema schema.json \
    --model openai/gpt-4o-mini \
    --output "outputs/$(basename "$file" .pdf).json"
done

For PDFs, combine with markitdown for text extraction:

for file in documents/*.pdf; do
  markitdown "$file" | struktur --stdin \
    --schema schema.json \
    --model openai/gpt-4o-mini \
    --output "outputs/$(basename "$file" .pdf).json"
done

Script approach

For more control, write a script that handles errors and tracks progress:

#!/bin/bash
 
SCHEMA="schema.json"
INPUT_DIR="./documents"
OUTPUT_DIR="./outputs"
MODEL="openai/gpt-4o-mini"
 
mkdir -p "$OUTPUT_DIR"
 
for file in "$INPUT_DIR"/*.{pdf,txt,docx}; do
  [-e "$file" ] || continue
  
  filename=$(basename "$file")
  output_file="$OUTPUT_DIR/${filename%.*}.json"
  
  echo "[$((++count))] Processing: $filename"
  
  if struktur --input "$file" \
       --schema "$SCHEMA" \
       --model "$MODEL" \
       --output "$output_file"; then
    echo "  ✓ Success: $output_file"
  else
    echo "  ✗ Failed: $filename" >&2
  fi
done
 
echo "Processed $count files"

TypeScript version with parallel processing:

import { extract, parallelAutoMerge } from "@mateffy/struktur";
import { openai } from "@ai-sdk/openai";
import { fileToArtifact } from "@mateffy/struktur";
import fs from "node:fs/promises";
import path from "node:path";
 
const schema = /* your schema */;
 
async function processDirectory(inputDir: string, outputDir: string) {
  await fs.mkdir(outputDir, { recursive: true });
  
  const files = await fs.readdir(inputDir);
  const documents = files.filter(f => 
    f.endsWith('.pdf') || f.endsWith('.txt')
  );
  
  for (const [index, filename] of documents.entries()) {
    console.log(`[${index + 1}/${documents.length}] ${filename}`);
    
    try {
      const buffer = await fs.readFile(path.join(inputDir, filename));
      const artifact = await fileToArtifact(buffer, {
        mimeType: filename.endsWith('.pdf') 
          ? 'application/pdf' 
          : 'text/plain'
      });
      
      const result = await extract({
        artifacts: [artifact],
        schema,
        strategy: parallelAutoMerge({
          model: openai("gpt-4o-mini"),
          dedupeModel: openai("gpt-4o-mini")
        })
      });
      
      const outputPath = path.join(
        outputDir, 
        `${path.parse(filename).name}.json`
      );
      await fs.writeFile(outputPath, JSON.stringify(result.data, null, 2));
      console.log(`  ✓ Saved to ${outputPath}`);
    } catch (error) {
      console.error(`  ✗ Failed: ${error.message}`);
    }
  }
}
 
await processDirectory("./documents", "./outputs");

Watch for new files

Process files as they arrive using inotifywait (Linux) or fswatch (macOS):

# Using inotifywait (Linux)
inotifywait -m ./incoming -e create -e moved_to |
  while read path action file; do
    echo "New file: $file"
    struktur --input "$path/$file" \
      --schema schema.json \
      --model openai/gpt-4o-mini \
      --output "processed/$file.json"
  done

Using fswatch (macOS):

fswatch -o ./incoming | while read f; do
  for file in ./incoming/*; do
    [-f "$file" ] || continue
    struktur --input "$file" \
      --schema schema.json \
      --model openai/gpt-4o-mini \
      --output "processed/$(basename $file).json"
    mv "$file" ./processed/
  done
done
