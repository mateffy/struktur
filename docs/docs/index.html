CLI

Extract in one command

Ingest, chunk, and extract in a repeatable CLI workflow. 

openstorage ingest ./contracts --schema schema.json
openstorage extract --strategy parallel --model "gpt-4o"
openstorage export --target snowflake

TypeScript

Compose in your app

Use the SDK to orchestrate extraction inside your pipelines. 

import { extract, parallel } from "openstorage";

const result = await extract({
  artifacts,
  schema,
  strategy: parallel({ model })
});
