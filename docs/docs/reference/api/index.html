TypeScript API Reference

Programmatic access to Struktur extraction.

API overview

TypeScript API for programmatic access. Import from @mateffy/struktur.

import { extract, simple } from "@mateffy/struktur";
import { openai } from "@ai-sdk/openai";

extract()

Main extraction function.

Signature

function extract<T>(
  options: ExtractionOptions<T>
): Promise<ExtractionResult<T>>

Parameters

NameTypeDescription
artifactsArtifact[]Array of artifacts to extract from
schemaTypedJSONSchema<T>JSON schema for validation
strategyExtractionStrategy<T>Extraction strategy instance
eventsExtractionEventsOptional event handlers for progress

Returns

ExtractionResult<T> with data, usage, and optional error.

Example

const result = await extract({
  artifacts,
  schema,
  strategy: simple({ model: openai("gpt-4o-mini") })
});
 
console.log(result.data);
console.log(result.usage); // { inputTokens, outputTokens, totalTokens }

Strategy factory functions

Functions to create strategy instances.

simple(config)

Single-shot extraction for small inputs.

import { simple } from "@mateffy/struktur";
 
const strategy = simple({
  model: openai("gpt-4o-mini"),
  outputInstructions: "Optional instructions for the model"
});

parallel(config)

Concurrent batch processing, then LLM merge.

import { parallel } from "@mateffy/struktur";
 
const strategy = parallel({
  model: openai("gpt-4o-mini"),
  mergeModel: openai("gpt-4o-mini"),
  chunkSize: 10000,
  concurrency: 3,
  maxImages: 5
});

sequential(config)

Process chunks in order with context preservation.

import { sequential } from "@mateffy/struktur";
 
const strategy = sequential({
  model: openai("gpt-4o-mini"),
  chunkSize: 10000
});

parallelAutoMerge(config)

Parallel with schema-aware merge and deduplication.

import { parallelAutoMerge } from "@mateffy/struktur";
 
const strategy = parallelAutoMerge({
  model: openai("gpt-4o-mini"),
  dedupeModel: openai("gpt-4o-mini"),
  chunkSize: 10000,
  concurrency: 3
});

sequentialAutoMerge(config)

Sequential with schema-aware merge and deduplication.

import { sequentialAutoMerge } from "@mateffy/struktur";
 
const strategy = sequentialAutoMerge({
  model: openai("gpt-4o-mini"),
  dedupeModel: openai("gpt-4o-mini"),
  chunkSize: 10000
});

doublePass(config)

Parallel pass for speed, sequential pass for refinement.

import { doublePass } from "@mateffy/struktur";
 
const strategy = doublePass({
  model: openai("gpt-4o-mini"),
  mergeModel: openai("gpt-4o-mini"),
  chunkSize: 10000
});

doublePassAutoMerge(config)

Double-pass with auto-merge and deduplication.

import { doublePassAutoMerge } from "@mateffy/struktur";
 
const strategy = doublePassAutoMerge({
  model: openai("gpt-4o-mini"),
  dedupeModel: openai("gpt-4o-mini"),
  chunkSize: 10000
});

Artifact helper functions

Functions to create artifacts from various sources.

fileToArtifact(buffer, options)

Create artifact from file buffer.

import { fileToArtifact } from "@mateffy/struktur";
import fs from "node:fs";
 
const buffer = fs.readFileSync("document.pdf");
const artifact = await fileToArtifact(buffer, {
  mimeType: "application/pdf",
  providers: /* optional custom providers */
});

urlToArtifact(url)

Fetch artifact from URL.

import { urlToArtifact } from "@mateffy/struktur";
 
const artifact = await urlToArtifact("https://example.com/document.pdf");

parseInputToArtifacts(input, options)

Parse various input formats to artifacts.

import { parseInputToArtifacts } from "@mateffy/struktur";
 
const artifacts = await parseInputToArtifacts(inputData, {
  providers: /* optional custom providers */
});

parseSerializedArtifacts(data)

Parse serialized artifact JSON.

import { parseSerializedArtifacts } from "@mateffy/struktur";
 
const artifacts = parseSerializedArtifacts(jsonString);

validateSerializedArtifacts(data)

Validate artifact JSON format.

import { validateSerializedArtifacts } from "@mateffy/struktur";
 
const isValid = validateSerializedArtifacts(jsonString);
