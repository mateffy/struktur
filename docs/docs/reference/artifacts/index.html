Artifacts Specification

Technical description of artifact types and creation.

Overview

Artifacts are JSON DTOs representing normalized input data. Struktur operates on artifacts you provide, not raw files.

Artifact type

Properties

PropertyTypeDescription
idstringUnique identifier
typeArtifactTypeType: text, image, pdf, file
raw() => Promise<Buffer>Function returning raw file data
contentsArtifactContent[]Array of content slices
metadataRecord<string, unknown>Optional additional metadata
tokensnumberOptional pre-computed token count

Example

{
  "id": "doc-001",
  "type": "pdf",
  "raw": async () => buffer,
  "contents": [
    {
      "page": 1,
      "text": "Document content...",
      "media": [...]
    }
  ],
  "metadata": {
    "filename": "document.pdf",
    "pageCount": 5
  }
}

ArtifactContent

Each content slice represents a portion of the artifact.

Properties

PropertyTypeDescription
pagenumberOptional page number
textstringOptional text content
mediaArtifactImage[]Optional embedded media

ArtifactImage

Media embedded in artifacts.

Properties

PropertyTypeDescription
type'image'Media type
urlstringOptional URL to media
base64stringOptional base64-encoded data
contentsBufferOptional raw buffer data
mimetypestringOptional MIME type

Example

{
  "type": "image",
  "id": "img-001",
  "mimetype": "image/png",
  "base64": "iVBORw0KGgo..."
}

Creation methods

CLI

# Load from file path
struktur --input file.pdf --schema schema.json
 
# Read from stdin (text or JSON)
cat document.txt | struktur --stdin --schema schema.json

TypeScript API

// From Buffer with MIME type
const artifact = await fileToArtifact(buffer, {
  mimeType: "application/pdf"
});
 
// Fetch from URL
const artifact = await urlToArtifact("https://example.com/doc.pdf");
 
// Parse artifact JSON
const artifacts = parseSerializedArtifacts(jsonString);

Provider registry

Registry mapping MIME types to artifact providers.

Example

const providers = {
  'application/pdf': async (buffer) => ({
    id: 'pdf-1',
    type: 'pdf',
    raw: async () => buffer,
    contents: [
      { page: 1, text: '...' },
      { page: 2, text: '...' }
    ]
  }),
  'text/plain': async (buffer) => ({
    id: 'text-1',
    type: 'text',
    raw: async () => buffer,
    contents: [
      { text: buffer.toString('utf-8') }
    ]
  })
};
 
const artifact = await fileToArtifact(buffer, {
  mimeType: "application/pdf",
  providers
});
