CLI Reference

Command-line interface for Struktur extraction.

CLI overview

The struktur CLI provides command-line access to extraction capabilities. Reads from files or stdin, outputs JSON.

struktur [command] [options]

struktur extract (default)

Main extraction command. When no command is specified, extract is assumed.

Flags

FlagTypeDescriptionDefault
--inputstringInput file path-
--stdinbooleanRead from stdinfalse
--schemastringPath to JSON schema file-
--schema-jsonstringInline JSON schema-
--modelstringModel spec (provider/model)-
--strategystringStrategy namesimple
--chunk-sizenumberTokens per chunk10000
--outputstringOutput file pathstdout
--providerstringLLM provideropenai

Examples

# Extract from file with schema file
struktur --input report.pdf --schema schema.json --model openai/gpt-4o-mini
 
# Extract from stdin
cat document.txt | struktur --stdin --schema schema.json --model anthropic/claude-3-haiku
 
# Extract with inline schema
struktur --input data.json \
  --schema-json '{"type":"object","properties":{"title":{"type":"string"}}}' \
  --model openai/gpt-4o-mini
 
# Use parallel strategy with custom chunk size
struktur --input large.pdf \
  --schema schema.json \
  --strategy parallel \
  --chunk-size 8000 \
  --model openai/gpt-4o-mini \
  --output result.json

struktur auth

Manage API tokens for providers.

Subcommands

auth set

Store a token for a provider.

struktur auth set --provider openai

Reads token from stdin. Paste key and press Enter, then Ctrl+D.

auth get

Retrieve a stored token.

struktur auth get --provider openai

auth delete

Remove a stored token.

struktur auth delete --provider openai

auth list

List all configured providers.

struktur auth list

auth default

Set or get default model.

# Set default model
struktur auth default --model openai/gpt-4o-mini
 
# Get default model
struktur auth default

struktur models

List available models for providers.

Flags

FlagDescription
--providerFilter by provider
--allShow all models including deprecated

Examples

# List all models
struktur models
 
# List models for specific provider
struktur models --provider openai

struktur verify

Validate artifact JSON format.

Flags

FlagDescription
--inputPath to artifact JSON file

Examples

# Verify artifact file
struktur verify --input artifacts.json
