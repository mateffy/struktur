Quickstart

Get started with Struktur in under 5 minutes. Extract structured data from any file.

Quickstart

Extract structured data from any file in 3 commands. About 5 minutes.

What we'll build

In this tutorial, we will extract structured invoice data from a text file. By the end, you'll have a working Struktur installation and your first successful extraction.

Prerequisites

  • Node.js 18+ or Bun installed
  • An API key from OpenAI, Anthropic, or Google

Step 1: Install

First, install Struktur globally using npm or Bun:

# Using npm
npm install -g @mateffy/struktur
 
# Or using Bun (recommended)
bun install -g @mateffy/struktur

Verify the installation:

struktur --version

You should see the version number printed.

Step 2: Configure your provider

Struktur needs an API key to call LLM providers. You have two options:

Option A: Environment variable (quick)

export OPENAI_API_KEY=sk-...

Option B: Secure storage (recommended)

struktur auth set --provider openai

This reads the key from stdin. Paste your key and press Enter, then Ctrl+D.

Step 3: Extract your first data

Now we'll create a simple test document and extract structured data from it.

First, create a test file:

echo 'Invoice #1234 from Acme Corp. Total: $1,250.00. Due: March 15, 2026.' > invoice.txt

Now extract the data:

struktur --input invoice.txt \
  --schema-json '{
    "type": "object",
    "properties": {
      "invoice_number": {"type": "string"},
      "vendor": {"type": "string"},
      "total": {"type": "number"},
      "due_date": {"type": "string"}
    },
    "required": ["invoice_number", "vendor", "total"]
  }' \
  --model openai/gpt-4o-mini

You should see output like this:

{
  "invoice_number": "1234",
  "vendor": "Acme Corp",
  "total": 1250,
  "due_date": "March 15, 2026"
}

:::note The LLM extracted the invoice number, vendor name, total amount, and due date from unstructured text. Struktur validated the output against your schema automatically. :::

What happened?

We used the simple strategy to extract data. Here's what Struktur did:

  1. Loaded the text file as an artifact
  2. Sent it to the LLM with your schema
  3. Validated the output matched the schema
  4. Returned the structured JSON

For a deeper understanding of how Struktur works, see the Concepts explanation.
