Struktur Documentation

Single-page reference for strategies, artifacts, validation, and merge behavior.

Overview

Struktur is a TypeScript extraction engine that takes pre-parsed artifacts and produces validated JSON with the Vercel AI SDK. It splits artifacts by token budgets, runs a configurable strategy, validates with Ajv, and merges or deduplicates outputs when needed.

Entry point: extract() delegates all work to the configured extraction strategy.

Installation

bun install

Struktur is published as struktur in package.json.

Quick start

import { extract, simple } from "struktur";
import type { JSONSchemaType } from "ajv";
import { google } from "@ai-sdk/google";

type Output = { title: string };

const schema: JSONSchemaType<Output> = {
  type: "object",
  properties: { title: { type: "string" } },
  required: ["title"],
  additionalProperties: false,
};

const result = await extract({
  artifacts: [/* Artifact[] */],
  schema,
  strategy: simple({ model: google("claude-haiku-4-5") }),
});

console.log(result.data.title);

Artifacts

Artifacts are JSON DTOs that already contain parsed text and media slices. Struktur does not parse PDFs, HTML, or images; it expects you to provide normalized artifacts that it can batch and feed to the LLM.

  • Use urlToArtifact or fileToArtifact for supported input types.
  • Register custom providers with registerArtifactProvider.
  • Artifacts can include text blocks and image references for multimodal models.

Chunking

Chunking splits large artifacts by token budgets and batches them for extraction. Strategies accept options like chunkSize and image limits so you can control memory and latency.

Chunking happens before extraction, and every strategy sees consistent batches.

Strategies

Choose the extraction flow that matches your data size and accuracy needs.

  • simple: single-shot extraction.
  • parallel: batch concurrently, then LLM merge.
  • sequential: batch sequentially with context preservation.
  • parallelAutoMerge: merge + dedupe automatically.
  • sequentialAutoMerge: safe merge + dedupe sequentially.
  • doublePass: refine after a full merge.
  • doublePassAutoMerge: auto-merge followed by refinement. 
import { extract, parallel } from "struktur";
import { google } from "@ai-sdk/google";

const result = await extract({
  artifacts,
  schema,
  strategy: parallel({
    model: google("claude-haiku-4-5"),
    mergeModel: google("claude-haiku-4-5"),
    chunkSize: 10_000,
  }),
});

Validation

Struktur validates every model output with Ajv. When validation fails, schema errors are fed back to the LLM and the run is retried. This keeps outputs aligned with your JSON schema.

Merge & dedupe

Merge behavior is schema-aware. Auto-merge strategies combine partial outputs, then run deduplication (hash-based or LLM-based depending on strategy settings).

Events

Use events to surface progress, messages, and errors in UI dashboards or logs. 

const result = await extract({
  artifacts,
  schema,
  strategy,
  events: {
    onStep: ({ step, total, label }) => {
      console.log("step", step, total, label);
    },
    onMessage: ({ role, content }) => {
      console.log(role, content);
    },
  },
});

Artifact providers

Providers let you plug in your own file handling. Register a handler for new MIME types and return a normalized artifact. 

import { registerArtifactProvider, fileToArtifact } from "struktur";

registerArtifactProvider("application/pdf", async (buffer) => ({
  id: "pdf-1",
  type: "pdf",
  raw: async () => buffer,
  contents: [{ page: 1, text: "..." }],
}));

const artifact = await fileToArtifact(buffer, { mimeType: "application/pdf" });

Custom strategies

Implement the ExtractionStrategy interface to plug in custom orchestration logic while keeping the same inputs and output contracts. 

import type { ExtractionStrategy } from "struktur";

const custom: ExtractionStrategy<{ ok: boolean }> = {
  name: "custom",
  run: async () => ({
    data: { ok: true },
    usage: { inputTokens: 0, outputTokens: 0, totalTokens: 0 },
  }),
};

Types & results

Use JSONSchemaType from Ajv for type-safe results. The return type is inferred from your schema, so result.data is strongly typed. 

import type { JSONSchemaType } from "ajv";

type Output = { title: string };
const schema: JSONSchemaType<Output> = {
  type: "object",
  properties: { title: { type: "string" } },
  required: ["title"],
  additionalProperties: false,
};
