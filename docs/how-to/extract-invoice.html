How to extract invoice data

Extract vendor, totals, and line items from invoices. About 3 minutes.

The problem: Extract invoice data

You have invoices (PDF or text) and need structured data: vendor name, invoice number, line items, totals, and due dates.

Define your schema

Create a JSON schema that describes the invoice structure. Include nested line items for complete extraction. 

// invoice-schema.json
{
  "type": "object",
  "properties": {
    "invoice_number": { "type": "string" },
    "vendor": { "type": "string" },
    "invoice_date": { "type": "string" },
    "due_date": { "type": "string" },
    "currency": { "type": "string" },
    "line_items": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "description": { "type": "string" },
          "quantity": { "type": "number" },
          "unit_price": { "type": "number" },
          "total": { "type": "number" }
        }
      }
    },
    "subtotal": { "type": "number" },
    "tax": { "type": "number" },
    "total": { "type": "number" }
  },
  "required": ["invoice_number", "vendor", "total"]
}

CLI approach

For a single invoice, use a direct command: 

struktur --input invoice.pdf \
  --schema invoice-schema.json \
  --model openai/gpt-4o-mini

For multiple invoices, use a shell loop: 

for file in invoices/*.pdf; do
  struktur --input "$file" \
    --schema invoice-schema.json \
    --model openai/gpt-4o-mini \
    --output "outputs/$(basename $file .pdf).json"
done

Or use a pipeline with markitdown for PDF conversion: 

find invoices -name "*.pdf" -exec markitdown {} \; | \
  struktur --stdin \
    --schema invoice-schema.json \
    --model openai/gpt-4o-mini

API approach

For application integration, use the TypeScript API: 

import { extract, simple } from "@mateffy/struktur";
import { openai } from "@ai-sdk/openai";
import { fileToArtifact } from "@mateffy/struktur";
import fs from "node:fs";

const schema = /* schema from above */;

const buffer = fs.readFileSync("invoice.pdf");
const artifact = await fileToArtifact(buffer, {
  mimeType: "application/pdf"
});

const result = await extract({
  artifacts: [artifact],
  schema,
  strategy: simple({
    model: openai("gpt-4o-mini")
  })
});

console.log(result.data);

For batch processing multiple invoices: 

import { parallelAutoMerge } from "@mateffy/struktur";

const files = await fs.promises.readdir("./invoices");
const artifacts = await Promise.all(
  files
    .filter(f => f.endsWith(".pdf"))
    .map(async f => {
      const buffer = await fs.promises.readFile(`./invoices/${f}`);
      return fileToArtifact(buffer, { mimeType: "application/pdf" });
    })
);

const result = await extract({
  artifacts,
  schema,
  strategy: parallelAutoMerge({
    model: openai("gpt-4o-mini"),
    dedupeModel: openai("gpt-4o-mini")
  })
});

Strategy choice

For simple single-page invoices, use simple. For multi-page invoices with many line items, use sequentialAutoMerge to handle potential duplicates across pages.

See How to choose a strategy for more guidance.
