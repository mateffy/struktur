How to extract real estate data

Extract property details and images from PDF exposés. About 3 minutes.

The problem: Extract real estate data

PDF real estate exposés contain property data, nested units, and images. You need structured extraction that handles multi-page documents with potential duplicate information.

Define your schema

Create a schema with nested units array and image descriptions: 

// property-schema.json
{
  "type": "object",
  "properties": {
    "property_name": { "type": "string" },
    "address": { "type": "string" },
    "description": { "type": "string" },
    "total_units": { "type": "number" },
    "units": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "unit_number": { "type": "string" },
          "size_sqm": { "type": "number" },
          "rent_per_month": { "type": "number" },
          "rooms": { "type": "number" },
          "floor": { "type": "string" },
          "features": {
            "type": "array",
            "items": { "type": "string" }
          }
        }
      }
    },
    "images": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "description": { "type": "string" },
          "location": { "type": "string" }
        }
      }
    }
  },
  "required": ["property_name", "address"]
}

Use sequentialAutoMerge

For real estate exposés, use sequentialAutoMerge:

  • Context preservation: Units on later pages can reference earlier context
  • Deduplication: Same unit may appear on multiple pages
  • Image handling: Processes embedded images alongside text

See How to choose a strategy for why this is the right choice.

Implementation

CLI approach

struktur --input exposé.pdf \
  --schema property-schema.json \
  --strategy sequentialAutoMerge \
  --model openai/gpt-4o-mini

API approach

import { extract, sequentialAutoMerge } from "@mateffy/struktur";
import { openai } from "@ai-sdk/openai";
import { fileToArtifact } from "@mateffy/struktur";
import fs from "node:fs";

const schema = /* schema from above */;

const buffer = fs.readFileSync("exposé.pdf");
const artifact = await fileToArtifact(buffer, {
  mimeType: "application/pdf"
});

const result = await extract({
  artifacts: [artifact],
  schema,
  strategy: sequentialAutoMerge({
    model: openai("gpt-4o-mini"),
    dedupeModel: openai("gpt-4o-mini"),
    chunkSize: 8000
  })
});

console.log(result.data);
