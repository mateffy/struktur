Structured data extraction

Reliably extract structured data
from any file

Struktur is an open-source data extraction engine which uses LLMs to turn unstructured documents and files into validated data.

Pick a strategy for small files or long documents, and it handles chunking, merging, and schema checks behind the scenes.

How it works

Three steps for consistent extraction output

Step 01

Ingest files

Add your files as plain text or in the artifact file format.

Step 02

Pick an extraction strategy

Use a built-in strategy or compose your own for the document type.

Step 03

Run extraction and validate

Structure executes your strategy and validates the output data to keep everything consistent.

data extraction harness

Use a pre-made extraction strategy or build your own

Struktur is a data extraction harness: a focused AI Agent for structured outputs. It gives you full control of how input context is passed into LLMs and the architecture to define exactly how the extraction should run, while taking care of how chunks are split, validated, and merged.

And strategies give your data extraction pipeline structure and rigidity while letting you define exactly what kind of logic you need during extraction without being in your way.

artifact format

An input format for any file type

The Struktur extraction logic doesn't directly deal with raw file contents. Instead, files are converted into the artifact file format before giving them to the extraction logic.

For page-based files, it even supports scoping each content to a page so that an LLM can work in a page-based meta.
