CLI example

$ struktur extract ./files/invoices/*.pdf \
  --schema ./schemas/invoice.json \
  --strategy parallel-auto-merge \
  --model openai:gpt-4.1

Output

{
  "invoice_id": "INV-4821",
  "vendor": "Northshore Supply",
  "currency": "USD",
  "total": 1824.5,
  "line_items": [
    { "sku": "CS-21", "qty": 3, "price": 249.5 }
  ]
}

TypeScript example

import { extract, parallel } from "@mateffy/struktur";
import { google } from "@ai-sdk/google";

const result = await extract({
  artifacts: files,
  schema,
  strategy: parallel({
    model: google("claude-haiku-4-5"),
    chunkSize: 10_000,
  }),
});

Output

{
  "catalog": {
    "title": "Spring 2026",
    "products": [
      { "id": "SKU-88", "name": "Field Jacket" }
    ]
  }
}

Extraction flow

Three steps, consistent output

Step 01

Ingest files

Add your files as plain text or in the artifact file format.

Step 02

Pick a strategy

Use a built-in strategy or compose your own for the document type.

Step 03

Run extraction and validate

Structure executes your strategy and validates the output data to keep everything consistent.

Artifact standard

A file format for any input

The artifact file format packages text, images, and metadata so any file can be extracted the same way. If you can write a converter, you can extract immediately.

Why it matters
Artifact schema (excerpt) Output can reference media
PDFs can include images and thumbnails; outputs can reference those slices.
Web pages, URLs, and binary files become uniform input data.
Merging happens inside strategies, keeping the artifact data and outputs consistent.

Use cases

Make any file structured

Invoices & receipts

Normalize totals, taxes, and line items with a schema.

{ "total": 1824.5, "currency": "USD" }

Real estate listings

Extract structured fields for listings and unit variants.

{ "beds": 3, "baths": 2, "price": 615000 }

Support tickets

Map free-form tickets into typed fields and routing.

{ "priority": "p1", "category": "billing" }

Product catalogs

Extract SKUs, variants, and embedded product images.

{ "sku": "SKU-88", "image_ref": "img-2" }

Research summaries

Pull sections, citations, and metrics into a schema.

{ "title": "", "findings": ["..."] }

Legal briefs

Track clauses, citations, and obligations per case.

{ "case": "A-112", "clauses": 12 }
