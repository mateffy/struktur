Structured data extraction

Reliably extract structured data
from any file

Struktur is an open-source data extraction engine which uses LLMs to turn unstructured documents and files into validated data.

Pick a strategy for small files or long documents, and it handles chunking, merging, and schema checks behind the scenes.

How it works

Three steps for consistent extraction output

Step 01

Ingest files

Add your files as plain text or in the artifact file format.

Step 02

Pick an extraction strategy

Use a built-in strategy or compose your own for the document type.

Step 03

Run extraction and validate

Structure executes your strategy and validates the output data to keep everything consistent.

data extraction harness

Use a pre-made extraction strategy or build your own

Struktur is a data extraction harness: a focused AI Agent for structured outputs. It gives you full control of how input context is passed into LLMs and the architecture to define exactly how the extraction should run, while taking care of how chunks are split, validated, and merged. Each strategy shapes how artifacts are chunked, routed to the LLM, and merged back into a schema-aligned result.

And strategies give your data extraction pipeline structure and rigidity while letting you define exactly what kind of logic you need during extraction without being in your way. Focus on making high-quality data extractions for your use case and let Struktur worry about everything else.

import { z } from "zod";
import { buildStrategy, type ExtractionContext } from "@mateffy/struktur";

const schema = z.object({
  name: z.string(),
  avatar: z.string(),
});

export const customStrategy = buildStrategy({
  id: "custom",
  chunkSize: 12_000,
  run: async ({ artifacts, model, validate }: ExtractionContext) => {
    const chunks = artifacts.chunkByTokens(12_000);
    const partials = await Promise.all(
      chunks.map((chunk) =>
        model.extract({
          schema,
          artifacts: chunk,
          system: "Extract profile data and return artifact refs.",
        })
      )
    );

    const merged = partials.reduce((acc, item) => ({ ...acc, ...item.data }), {});
    return validate(merged);
  },
});

artifact format

An input format for any file type

The Struktur extraction logic doesn't directly deal with raw file contents. Instead, files are converted into the artifact file format before giving them to the extraction logic. This simplifies the actual strategies by always dealing with input data in the same format, no matter the actual input file type.

For page-based files, it even supports scoping each content to a page so that an LLM can work in a page-based meta. In addition, it also includes all of the embedded images, which can be referenced by the LLM in the output data and later retrieved from the input file directly.

It is also trivial to write your own artifact ingester and add it both to the local command-line usage, as well as to any TypeScript usage in your project.

reference media in data

Extract embedded media and reference it in your data

Ask the model to reference embedded media and Struktur returns those assets alongside the data, so you can attach them directly to records and reuse visuals as product shots, avatars, or evidence without re-uploading or re-mapping. Each media slice stays linked to its source, so your output can point back to the exact image with a stable reference.

Use cases

Extract structured data from anything

Invoices & receipts

Normalize totals, taxes, and line items with a schema.

{ "total": 1824.5, "currency": "USD" }

Real estate listings

Extract structured fields for listings and unit variants.

{ "beds": 3, "baths": 2, "price": 615000 }

Support tickets

Map free-form tickets into typed fields and routing.

{ "priority": "p1", "category": "billing" }

Product catalogs

Extract SKUs, variants, and embedded product images.

{ "sku": "SKU-88", "image_ref": "img-2" }

Research summaries

Pull sections, citations, and metrics into a schema.

{ "title": "", "findings": ["..."] }

Legal briefs

Track clauses, citations, and obligations per case.

{ "case": "A-112", "clauses": 12 }
