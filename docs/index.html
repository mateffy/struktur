Struktur

Struktur is a TypeScript-first extraction engine that turns parsed artifacts into validated JSON using the Vercel AI SDK. It batches content by token budgets, runs strategy-driven workflows, validates with Ajv, and merges or dedupes where needed.

How it works
A predictable extraction pipeline you can audit and control.
1. Provide artifacts

Artifacts are JSON DTOs with text and media slices. You bring your own parsing pipeline.

2. Select a strategy

Run extraction in parallel, sequentially, or with an auto-merge and dedupe pass.

3. Validate and merge

Ajv validation retries on schema errors, then results merge with schema-aware rules.

Token-aware chunking

Split artifacts by token limits, preserve image budgets, and batch reliably for LLM calls.

Strategy orchestration

Choose from simple, parallel, sequential, auto-merge, or double pass refinement workflows.

Schema-first validation

Ajv validates every output, then feeds errors back to the LLM for targeted retries.

Merge and dedupe

Merge outputs using schema-aware rules and optional LLM dedupe for clean results.

Quick start
A minimal extraction flow that returns typed data. 
import { extract, simple } from "struktur";
import type { JSONSchemaType } from "ajv";
import { google } from "@ai-sdk/google";

type Output = { title: string };

const schema: JSONSchemaType<Output> = {
  type: "object",
  properties: { title: { type: "string" } },
  required: ["title"],
  additionalProperties: false,
};

const result = await extract({
  artifacts: [/* Artifact[] */],
  schema,
  strategy: simple({ model: google("claude-haiku-4-5") }),
});

console.log(result.data.title);
