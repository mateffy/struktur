

The Struktur CLI provides commands for data extraction and authentication management.

Commands [#commands]

* [installation](/docs/cli/installation) — Install and configure Struktur
* [extract](/docs/cli/extract) — Extract structured data from documents
* [auth](/docs/cli/auth) — Manage API tokens and default models
* [models](/docs/cli/models) — List available models by provider
* [verify](/docs/cli/verify) — Verify configuration and provider connectivity
