---
title: Installation
description: Install the Struktur TypeScript SDK.
---

```bash
npm install @mateffy/struktur
# or
bun add @mateffy/struktur
```

Peer dependency: `typescript ^5`.

The package exports all types, functions, and strategy factories from the entrypoint. The `@ai-sdk/anthropic`, `@ai-sdk/google`, `@ai-sdk/openai`, and `@openrouter/ai-sdk-provider` packages are bundled as dependencies — you do not need to install them separately.

## Exports

```js
// Main function
import { extract } from "@mateffy/struktur";

// Strategy factories
import { simple, parallel, sequential, parallelAutoMerge, sequentialAutoMerge, doublePass, doublePassAutoMerge } from "@mateffy/struktur";

// Artifact helpers
import { parse, fileToArtifact, urlToArtifact } from "@mateffy/struktur";
```
